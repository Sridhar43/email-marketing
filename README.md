# 📧 Email Marketing App

A full-stack Email Marketing application built using the MERN Stack. This project allows companies to manage contacts, create email campaigns, and send emails efficiently.

## 🚀 Features

- User Authentication (Signup/Login)
- Secure JWT Authentication
- Company Dashboard
- Contact Management
- Create & Manage Email Campaigns
- Send Emails
- Campaign History
- Responsive UI
- Protected Routes

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS / Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcrypt
- Nodemailer
- dotenv

## ⚙️ Installation

### Clone Repository

bash
git clone <repository-url>


### Backend Setup

bash
cd server
npm install
npm run dev


### Frontend Setup

bash
cd client
npm install
npm start


## 🔑 Environment Variables

Create a .env file inside the *server* folder.

env
PORT=4000

MONGODB_URL=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

EMAIL_USER=your_email

EMAIL_PASS=your_email_app_password


## ▶️ Running the Project

Backend

bash
npm run dev


Frontend

bash
npm start
